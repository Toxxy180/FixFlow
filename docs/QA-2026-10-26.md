## ขอบเขตข้อมูลและข้อจำกัด

การสลับสามบทบาท การระงับบัญชี และการจองในเบราว์เซอร์ใช้ PostgreSQL จำลองในเครื่องแยกจาก Supabase จริง การตรวจอีเมลซ้ำและ provider เป็นการอ่านระบบจริง ไม่มีการเปลี่ยนสิทธิ์/ระงับบัญชีจริงหรือส่ง OTP ออกไป

Migration เพิ่มสถานะบัญชีและฟังก์ชันตรวจอีเมลถูกใช้กับ Supabase จริงแล้ว ไม่มีการลบหรือเขียนทับประวัติเดิม เซิร์ฟเวอร์ทดสอบและฐานข้อมูลจำลองถูกหยุดหลังจบ ส่วน dev server ปกติเปิดที่ localhost:3000 ด้วย .env เดิม

ยังต้องทดสอบด้วยเจ้าของอีเมล: รับ OTP สมัครครั้งแรก, ส่งซ้ำกับบัญชีที่ยังไม่ยืนยัน, ล็อกอินด้วยรหัสผ่านจริง และเปิดลิงก์กู้รหัสผ่านในเบราว์เซอร์เดิม การทดสอบ SDK แบบจำลองไม่ยืนยันการส่งถึงกล่องอีเมล/โควตา SMTP และรอบนี้ไม่ได้ Deploy หรือ Push GitHub
